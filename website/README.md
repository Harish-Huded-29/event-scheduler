# Event Scheduler — Showcase Website

Showcase landing page and APK distribution portal for **Event Scheduler** built with React + Vite and deployed on Vercel.

🔗 **Live Portal**: [https://event-s.vercel.app](https://event-s.vercel.app)

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
The output directory `dist` is configured in `vercel.json` for deployment.
